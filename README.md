# Cripta dei Numeri Rotti

Dungeon crawler didattico per la **seconda media**: operazioni con le frazioni, proporzioni e proprietà delle proporzioni.
Ogni mostro è una domanda: risposta giusta = colpo, risposta sbagliata = mezzo cuore, con il procedimento mostrato sempre.

## Come si gioca
- **Tablet:** trascina il dito per muoverti, tocca le risposte.
- **PC:** WASD o frecce, tasti 1–4 per rispondere, Invio per continuare.

Nel menu si sceglie il percorso (completo o un solo argomento) e il tempo per domanda.
A fine partita compare un resoconto per argomento, copiabile con un pulsante.

## Pubblicazione con GitHub Pages
1. Carica `index.html`, `README.md` e `.nojekyll` nella radice del repository.
2. Vai su **Settings → Pages**.
3. In *Build and deployment* scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, poi **Save**.
4. Dopo un minuto il gioco è online su `https://<tuo-utente>.github.io/<nome-repo>/`.

Il gioco è un unico file HTML senza dipendenze: funziona anche aperto in locale (servono solo i Google Fonts, se c'è connessione).
